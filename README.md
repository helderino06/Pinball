# Neon Rush Pinball V3

Esta versión cambia el planteamiento visual y de control para parecerse más a una mesa de pinball real.

La referencia conceptual son mesas modernas de Stern: múltiples tiros definidos, rampas, spinner, targets, varios flippers, modos y multiball. No copia arte, personajes ni layouts concretos.

En especial se toman como referencia ideas documentadas en Godzilla de Stern: rampas y wireforms, targets, spinner, tres flippers, multiball y un objetivo central. https://sternpinball.com/game/godzilla/

## Controles iPad
- Botón izquierdo: flipper izquierdo.
- Botón derecho: flipper derecho.
- Botón vertical LAUNCH HOLD: mantener para cargar y soltar para lanzar.
- PAUSE / SOUND en el lateral.
